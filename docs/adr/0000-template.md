## Context

What forces are at play? What constraint, requirement, or problem makes a decision
necessary? State facts and measurements here, and label anything you are assuming as an
assumption. If you are guessing at a number, say so.

## Options considered

| Option | Pros | Cons |
|---|---|---|
| A | | |
| B | | |
| C — do nothing | | |

Always include the null option. "Do nothing" losing on its merits is a stronger result than
never having considered it.

## Decision

We will <do X>.

State it in one sentence. If it takes a paragraph, the decision is actually several
decisions and belongs in several ADRs.

## Consequences

**Accepted costs.** What gets worse. Be specific — this is the section future-you will
actually read.

**Risks and failure modes.** What breaks this decision, and what the early warning sign
looks like.

**Revisit when.** The concrete condition under which this should be reopened. Not "if
problems arise" — something observable, like "if a single scan exceeds 60 seconds" or "if
the schema changes twice in one month."
